1. Abstract

Estimating the fair resale price of a pre-owned automobile is a multivariate regression problem driven by vehicle age, distance driven, brand value, engine capacity, fuel type, transmission, and ownership history. This project implements an end-to-end Used Car Price Prediction pipeline in R across 500 listings spanning 10 automotive brands. Following data cleaning, median missing-value imputation, and feature engineering, four models are trained and benchmarked on an 80/20 train-test split: Multiple Linear Regression, Stepwise AIC Linear Regression, Log-Transformed Linear Regression, and Decision Tree Regression (rpart). The Log-Transformed Linear Regression model achieves the strongest test performance (R² = 0.9585, RMSE = 0.4600 Lakhs, MAE = 0.3028 Lakhs, MAPE = 6.43%), capturing exponential resale depreciation far better than additive models.

2. Problem Statement & Objectives

4. Methodology

4.1 Data Cleaning & Feature Engineering

  • Missing-Value Imputation: 8 missing values in Mileage_kmpl and 6 missing values in Power_bhp were imputed with their respective medians (19.30 kmpl and 106.40 bhp).
  • Feature Engineering: Derived Car_Age = 2026 - Year and converted categorical variables into R factors.
  • Train-Test Split: Partitioned into 400 training rows (80%) and 100 test rows (20%) with set.seed(123).

4.2 Regression Models Implemented

  • Multiple Linear Regression (stats::lm): Additive baseline using all predictors.
  • Stepwise AIC Regression (MASS::stepAIC): Bidirectional feature selection minimizing Akaike Information Criterion.
  • Log-Transformed Linear Regression: Fits log(Selling_Price_Lakhs) with bias-corrected smearing back-transformation exp(pred + 0.5 * sigma^2) to model exponential depreciation.
  • Decision Tree Regressor (rpart::rpart): Non-parametric regression tree (cp = 0.01, maxdepth = 6).

7. Conclusion & Future Work

Modeling log-transformed used car prices captures multiplicative depreciation across age, mileage, brand, and drivetrain features effectively, reducing test RMSE by 36.6% (from 0.7258 to 0.4600 Lakhs) and cutting MAPE in half (from 12.85% to 6.43%) relative to standard linear regression. Future enhancements include training Random Forest / Gradient Boosting models and wrapping the predictor in an interactive R Shiny dashboard.
